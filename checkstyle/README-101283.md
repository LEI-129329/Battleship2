# Checkstyle Quality Gate - LEI-101283

## Tipo de Identificador Escolhido
**ConstantName (Nomes de Constantes)**

## Tabela de Mapeamento

| Elemento | Regra Checkstyle | Expressão Regular | O que não é possível verificar |
| :--- | :--- | :--- | :--- |
| Nomes de Constantes | `ConstantName` | `^[A-Z][A-Z0-9_]*$` (UPPER_SNAKE_CASE) | O Checkstyle garante o formato, mas não consegue avaliar se o nome da constante é semanticamente significativo para o domínio do problema. |

## Reflexão

O Checkstyle permitiu garantir que as constantes do projeto seguem a convenção de nomenclatura `UPPER_SNAKE_CASE`, o que melhora a legibilidade e a consistência do código. No entanto, a ferramenta baseia-se em expressões regulares e não consegue avaliar a semântica dos nomes (por exemplo, se `MAX_SHIPS` representa realmente o número máximo de navios no contexto do jogo). Além disso, a configuração é rígida: qualquer constante que não cumpra o padrão faz falhar o portão, o que é útil para manter a disciplina, mas pode gerar falsos positivos se o projeto tiver convenções específicas diferentes das definidas.
